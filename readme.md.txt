# DNA Sequence Toolkit

A beginner-friendly bioinformatics project developed using Python and Biopython.

## Project Overview

This tool performs basic DNA sequence analysis from FASTA files.

## Features

- DNA sequence reading
- GC content calculation
- Reverse complement generation
- DNA to protein translation

## Technologies Used

- Python
- Biopython

## Installation

```bash
pip install biopython
```

## Running the Project

```bash
python main.py
```
